---
name: 系统与进程内存应保留跨来源数值对比
description: 用户要求补算系统剩余内存，系统及进程内存跨来源均展示差值，进程保留排行
type: feedback
---

系统内存总量和已用已知时应提供剩余内存；系统和进程内存都不能仅因采集来源不同或混合就禁止数值对比。进程内存应展示差值、相对变化并参与排行。

**Why:** 用户指出剩余量缺失不符合分析需求，并明确要求进程内存也应进行对比，不接受仅凭潜在口径差异隐藏结果。
**How to apply:** 剩余量逐样本计算再统计；跨来源保留数值差异与排行并提示缓存、GPU 回填等潜在口径差异，不直接判定退化。缺失不补零，基准为零不计算相对变化。
