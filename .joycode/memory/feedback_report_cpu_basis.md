离线报告整体概览的整机 CPU 改用单核口径：单核满载100%，整机总占用可超过100%；CPU图、CPU表、内存图、内存表按此顺序纵向独占整行。进程仍使用单核 CPU，KDMIPS继续按单核CPU百分比 / 100 × 28.75换算。

**Why:** 用户于2026-09-23明确要求离线报告整机CPU改单核口径、CPU和内存图格分行，此要求覆盖2026-09-20的离线概览整机100%口径决定。用户另明确：CPU 总占用只是展示样式举例，精简统计列不代表删除其他 CPU 指标行。
**How to apply:** 保留全部 CPU 指标行，表格仅展示均值、P95、峰值，表头及各指标展示项统一加粗美化。概览曲线与均值、P95/P99保持单核口径，逐样本换算后全量统计；未知换算比例留空。CPU超标判断仍采用整机满载100%口径并明确标注。此次要求针对离线报告，不据此推断应用内页面也需改动。进程单核缺失不回退整机CPU。
