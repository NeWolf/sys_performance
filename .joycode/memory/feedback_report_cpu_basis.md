---
name: 区分整机CPU百分比与进程单核算力口径
description: 整体概览整机满载100%，进程统计及KDMIPS换算仍使用单核CPU
type: feedback
---

应用内页面与导出报告保持统一：整体概览的整机 CPU 满载按 100%，不推断或乘核数；空闲为 100% 减整机总占用。进程继续采用单核 CPU，P95K = 单核 CPU P95 / 100 × 28.75；峰值K同理，单位 KDMIPS。

**Why:** 用户于 2026-09-18 要求进程算力使用单核口径，并于 2026-09-20 明确整体概览应采用整机100%口径，重点突出总占用及P95/P99。
**How to apply:** 不将进程单核口径套用于整机概览；进程表、排序、趋势及合并仍使用单核，缺失不回退整机CPU。概览内存使用MemTotal−MemAvailable，含不可回收部分，不把可回收cache算作已用。
